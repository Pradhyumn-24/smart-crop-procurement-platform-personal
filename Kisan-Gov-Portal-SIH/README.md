# किसान सूचना एवं सेवा पोर्टल — SIH Frontend

यह HTML + CSS + JavaScript आधारित government-style frontend prototype है।

## Included
- Government-style utility bar + branding header
- Uploaded logo placed in the top-left branding area
- Tagline: हर किसान की बारी, सही समय की जानकारी
- Ministry: Ministry of Consumer Affairs, Food and Public Distribution
- UIDAI-inspired navigation/footer structure (not a copy)
- Working multimedia slider with 3 local SVG slides + video-ready slide
- Responsive mobile navigation
- Home, About, Services, Dashboard, Reports, Contact, Login pages
- No framework required

## Run
Open `index.html` in Chrome/Edge/Firefox.

## Add your own multimedia
Put your own MP4 at:
`assets/media/intro.mp4`

You can replace the three files in `assets/slides/` with your own JPG/PNG/SVG banners, keeping the same filenames.

## Important
This is an SIH prototype, not an official Government of India website. Replace demo statistics, contact details, links, and authentication with your team's actual backend/data before deployment.
